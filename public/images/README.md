# Your photos go here

Put your two photos of Ja in this folder with these exact names:

- `ja-1.jpg` — the circular photo on the opening screen (also the first Polaroid)
- `ja-2.jpg` — the second Polaroid

Want different names or more photos? Edit `src/content/site.ts`.
Until the files are here, the site shows a tasteful blank frame — never a stock photo.
